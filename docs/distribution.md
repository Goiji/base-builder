# Distribution primitives

## TokenVesting

Linear vesting with a configurable cliff. Releasable tokens accrue over
time and can be pulled by the beneficiary.

## MerkleAirdrop

Gas-efficient airdrop where eligibility is proven with a merkle proof.
Only claimants in the tree can claim, and each can claim once.

## PaymentSplitter

Splits incoming native ETH across a fixed set of payees by shares.
