# Libraries

- `LibMath` — min / max / absolute diff.
- `LibPercent` — basis-point math with round-up and round-down variants.
- `LibMerkle` — merkle proof verification wrapper.
- `LibAddress` — EOA vs contract detection.
- `LibBytes` — byte trimming.
- `LibSignatures` — ECDSA recovery wrapper.
- `Lib712` — EIP-712 domain separator builder.
