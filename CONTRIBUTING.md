# Contributing

Thanks for helping build in the open.

## Development

```bash
forge install foundry-rs/forge-std --no-commit
forge build
forge test
```

## Branching

- Work on a feature branch.
- Open a pull request into `main`.
- Keep commits small and message style consistent with existing history.

## Conventions

- Solidity follows forge fmt.
- New public entry points need a Foundry test.
